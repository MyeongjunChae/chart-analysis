# 차트 분석

OHLCV 가격 CSV를 업로드해 캔들 차트, 기술 패턴, 과거 패턴 빈도, 근사 거래량 프로파일, 피보나치 되돌림, 몬테카를로 시나리오를 확인하는 로컬 Streamlit 앱입니다.

## 실행

Python 3.10 이상에서 프로젝트 폴더를 연 뒤:

Windows PowerShell:

    py -m venv .venv
    .\.venv\Scripts\Activate.ps1
    python -m pip install -r requirements.txt
    streamlit run app.py

## CSV 형식

TradingView에서 내보낸 OHLCV CSV를 올리세요. 시간(선택), 시가(Open), 고가(High), 저가(Low), 종가(Close) 열이 필요합니다. 거래량(Volume)이 있으면 매물대 계산에 사용합니다. 열 이름이 자동 감지되지 않으면 왼쪽 메뉴에서 직접 연결하세요.

## 포함 기능

- 캔들: 도지, 슈팅스타, 망치형, 상승/하락 장악형
- 차트 구조: 상승 삼각형, 상승/하락 쐐기, 베어 페넌트, 헤드앤숄더 및 역헤드앤숄더
- OHLCV 차트, 거래량, 근사 POC/VAH/VAL, 최근 스윙 피보나치 되돌림
- 추세·모멘텀·가격 위치·거래량/CVD 추정·패턴을 합산한 종합 방향 점수
- 봉 방향으로 계산한 근사 CVD 차트와 상대 거래량
- 패턴별 과거 방향 적중률, 표본 수, 95% Wilson 구간, 중앙 수익률
- 최근 로그수익률 부트스트랩 몬테카를로 분위수 경로

종합 방향 점수는 정규화된 기술 신호를 합산한 값이며 보정된 예측 확률이나 투자 지시가 아닙니다. CVD는 봉 방향으로 거래량에 부호를 붙인 근사값이며 실제 체결 단위의 매수/매도 델타가 아닙니다. 패턴은 데이터 구간과 변동성에 따라 오탐/미탐이 생길 수 있습니다. 패턴 빈도는 과거 표본 통계이며 매매 성공 확률이나 수익을 보장하지 않습니다. 몬테카를로 역시 시나리오 분석이며 거래 비용, 슬리피지, 유동성, 시장 구조 변화는 반영하지 않습니다.
