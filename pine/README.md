# 차트 종합 분석 · Pine Script

차트_종합_분석.pine은 TradingView Pine Script v6용 단일 지표입니다.

## 포함 기능

- FRAMA, VWMA 편차 밴드, STARC, 이동평균, 피보나치 되돌림
- 두 번째 지표의 Insync 투표, WaveTrend, STC, TMO, 정규화 이동평균 오실레이터
- 최근 스윙 피벗 지지/저항과 HLC3 거래량을 가격 구간에 배분한 근사 매물대
- 도지, 슈팅스타, 망치형, 상승/하락 장악형 표시
- 추세·모멘텀·가격 위치·거래량/CVD 추정·캔들 신호를 합산한 0–100 방향 점수
- 설정 기준을 넘을 때 차트 표시와 알림

TradingView에서 Pine Editor를 열고 .pine 파일 내용을 붙여넣은 다음 차트에 추가를 누르세요. 알림은 지표 추가 후 알림 만들기에서 두 종합 점수 조건을 선택하면 됩니다.

## 점수와 한계

매수 점수와 매도 점수는 서로 보완되는 기술 신호 점수이며, 수익 확률로 보정된 숫자가 아닙니다. CVD는 봉의 시가와 종가 방향으로 거래량에 부호를 붙인 근사치입니다. 매물대도 봉의 HLC3와 거래량으로 계산합니다. 실제 체결 단위 매수/매도 흐름은 아닙니다.

복합 차트 패턴의 과거 빈도, 헤드앤숄더·쐐기·삼각형 판정, 몬테카를로 시나리오와 가격 CSV 업로드는 저장소 루트의 Python 앱에서 제공합니다.
